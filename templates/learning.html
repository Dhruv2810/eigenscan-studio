NOTEBOOK 1

Foundations on structured breast cancer data

The first notebook uses the Breast Cancer Wisconsin dataset to understand the mathematical and practical behavior of PCA, LDA and SVM before moving to ultrasound pixels.

WHAT WE DID

Notebook 1 workflow

  1. Load and inspect569 samples with 30 numerical features.
  2. Encode labelsBenign = 0 and malignant = 1 so malignant metrics are directly measured.
  3. Split the data455 training samples and 114 testing samples using stratification.
  4. StandardizeFit StandardScaler on training data and transform the test data with the same statistics.
  5. Understand PCA manuallyCenter data, calculate covariance, eigenvalues and eigenvectors, then retain enough components for 90% variance.
  6. Apply library PCAReduce 30 features to 7 principal components while retaining 91.14% of variance.
  7. Train LDA and SVMCompare LDA, Linear SVM and RBF SVM on original and PCA features.
WHAT WE LEARNT

Key learning from Notebook 1

PCA is unsupervised

It finds directions with maximum variance without using class labels.

Eigenvalues rank importance

Larger eigenvalues represent principal directions that explain more variance.

Eigenvectors define directions

They form the new PCA axes used to project the original feature space.

LDA is supervised

It uses class labels and focuses on separating benign and malignant classes.

SVM depends on the feature space

Linear and RBF kernels behave differently before and after dimensionality reduction.

Notebook 1 conclusion

PCA reduced the feature space from 30 variables to 7 components while preserving more than 91% of the variance. The comparison showed that the PCA representation worked especially well with Linear SVM, giving the highest malignant recall and the fewest false negatives on the test split.

Evaluation framework

How every model is measured

Malignant is the positive class throughout the project, so precision, recall and F1 directly describe malignant-case performance.

Accuracy (TP + TN) / (TP + TN + FP + FN)

Overall proportion of correct predictions.

Malignant precision TP / (TP + FP)

Of all cases predicted malignant, how many were actually malignant.

Malignant recall TP / (TP + FN)

Of all actual malignant cases, how many the model detected.

F1-score 2 x (Precision x Recall) / (Precision + Recall)

A single measure that balances precision and recall.

TP True positive TN True negative FP False positive FN False negative

WHAT WE DID

Notebook 2 workflow

  1. Combine the supplied image splits780 grayscale ultrasound images in total.
  2. Encode malignant as positiveBenign = 0 and malignant = 1.
  3. Reserve an untouched set39 images are removed before training and evaluation for the live web demo.
  4. Flatten every scan128 x 128 becomes a 16,384-dimensional pixel vector.
  5. Standardize training pixelsThe fitted scaler is reused for test, demo and uploaded scans.
  6. Apply one PCA model16,384 features become 118 principal components while retaining 90.01% variance.
  7. Compare five model pathsLDA on PCA, Linear SVM, RBF SVM, PCA plus Linear SVM, and PCA plus RBF SVM.
WHAT WE LEARNT

Key learning from Notebook 2

Image pixels create a very high dimensional space

Each scan starts with 16,384 numerical pixel values.

PCA compresses the image representation

Only 118 components are needed to retain slightly above 90% of training variance.

Eigen-Scans visualize PCA directions

Each principal component can be reshaped back into a 128 x 128 image-like pattern.

Accuracy alone changes the winner

PCA plus RBF SVM has the highest accuracy, but it detects fewer actual malignant cases.

Model choice depends on the declared priority

Our final rule places malignant recall first, then accuracy, F1, precision and false negatives.

Notebook 2 conclusion

The image experiment reduced 16,384 pixel features to 118 PCA components and compared five classical model paths. PCA plus RBF SVM produced the highest test accuracy, but PCA plus Linear SVM detected the largest proportion of malignant cases and produced the fewest false negatives. Based on the project's declared multi-metric priority, PCA plus Linear SVM is selected for deployment.
