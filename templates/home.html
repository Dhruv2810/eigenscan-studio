Problem statement

Breast cancer classification requires distinguishing between benign and malignant cases using available clinical or image-based data. This project performs a comparative analysis of classical machine learning techniques to study how different feature representations and classification models perform in breast cancer detection.

02

Objective

Develop and comparatively evaluate PCA, LDA and SVM based approaches for benign versus malignant classification, then identify the strongest predictive model using multiple performance measures rather than accuracy alone.

Comparative framework

One question, multiple model paths
